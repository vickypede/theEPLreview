## Data Model Recommendation

Make `isCurrentPremierLeague` the source of truth for active Premier League membership.

Every club document should carry:

```json
{
  "isCurrentPremierLeague": true,
  "season": "2026-27"
}
```

If `isCurrentPremierLeague` is not `true`, the club should be treated as inactive for the current EPL experience.

Use `isCurrentPremierLeague` to decide what appears in:

- `/clubs`
- Header club dropdown
- Homepage club fallback selection
- Profile club selector
- Admin source club selector
- Any future sitemap club entries
- Club detector/tagging during new article ingestion
- Whether club-specific sources should run

Use `isTop6` only for:

- Priority ingestion grouping
- Homepage top-six club cards
- Default followed clubs for new users

Keep `isTop6` for deliberate editorial priority. It should not be used as the source of truth for current Premier League membership.

## Priority / Top Six Logic

Preserve the existing deliberate behavior:

- `group=top6` runs general sources plus sources tagged to current clubs where `isTop6` is `true`.
- `group=other14` runs general sources plus sources tagged to current clubs where `isTop6` is `false`.
- General sources with `clubSlugs: []` run in both grouped jobs.
- Sources tagged only to inactive clubs should not run.

```text

  Run the source.
```
